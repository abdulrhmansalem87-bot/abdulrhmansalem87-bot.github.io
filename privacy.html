Privacy Policy

Last updated: November 26, 2026.

NewsFlow YouTube Uploader Bot ("the App") is a personal automated pipeline that uploads videos to the YouTube channel owned by the same person who operates the App. It is not offered to the public and has no other users.

Data we access

The App uses Google OAuth with the YouTube upload permission, only for the operator own Google account, to upload videos and set their titles, descriptions and visibility on the operator own channel.

How data is used

Access tokens are stored privately by the operator and used only to perform these uploads. We do not collect, sell, share or disclose personal data to any third party. We do not use Google user data for advertising.

Retention and deletion

Tokens are kept only while the App is in use. The operator can revoke access at any time at https://myaccount.google.com/permissions, which deletes the App access.

Google API Services

The use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
